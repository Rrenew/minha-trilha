Início O que aprendi Comandos Git

Cada commit é um passo na trilha.

Aqui registro o que estou aprendendo sobre desenvolvimento web e controle de versão com Git e GitHub.

O que aprendi

  1. HTML

    Estruturar uma página com cabeçalho, seções e rodapé usando tags semânticas.

  2. CSS

    Organizar o layout com flexbox e grid, e definir cores e tipografia com variáveis.

  3. Git

    Salvar o histórico do projeto em commits, trabalhar em branches e unir tudo com merge.

  4. GitHub

    Publicar o repositório e manter uma cópia remota do projeto.
