O que aprendi

    Estruturar uma página com cabeçalho, seções e rodapé usando tags semânticas.

  2. CSS

    Organizar o layout com flexbox e grid, e definir cores e tipografia com variáveis.

  4. GitHub

    Publicar o repositório e manter uma cópia remota do projeto.

Comandos Git

git init
Cria um repositório novo na pasta atual.
git status
Mostra o que mudou e o que está pronto para commit.
git add .
Prepara todas as alterações para o próximo commit.
git commit -m "mensagem"
Registra as alterações preparadas no histórico.
git log --oneline
Lista o histórico de commits, um por linha.
git branch
Lista as branches ou cria uma nova.
git switch -c nome
Cria uma branch e muda para ela.
git merge nome
Traz para a branch atual as mudanças da branch indicada.
git remote add origin URL
Conecta o repositório local ao GitHub.
git push -u origin main
Envia os commits para o GitHub.
